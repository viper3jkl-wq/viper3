# Viper3 · 本地视频质检与 SRT 字幕校对工具

Viper3 是一款在浏览器中本地运行的视频质检与字幕校对工具，集画面异常检测、SRT 批量校对、同步视频复核和历史报告管理于一体。应用以单个 HTML 文件交付，无需安装依赖、无需后端服务，素材不会主动上传到云端。

当前仓库版本：**Viper3 v1.2**

## 主要功能

### 画面异常检测

- 导入单个视频、多个视频或整个文件夹。
- 检测黑帧与疑似夹帧，提供严格、均衡、宽松三种预设。
- 可调整像素亮度、暗像素占比、持续时长、画面突变和回归阈值等参数。
- 支持 MP4 / MOV / MKV / WebM / TS 等常见容器。
- 基于浏览器 WebCodecs 的 FastEngine 顺序解码，避免逐帧来回 seek。
- 支持 H.264 / H.265 / AV1 / VP9 / VP8 等浏览器可解码编码。
- 夹帧判定会比较剪辑点附近的短帧序列，并识别镜头尾部单帧突变，减少快速蒙太奇和纯亮度跳变误报。
- 显示真实帧率、异常时间码、帧范围、置信度和结果汇总。
- 支持统一视频预览、上一帧 / 下一帧检查、点击结果直接定位异常帧。
- 支持历史报告回看和异常截图缩略图。

### SRT 字幕校对

- 批量导入 SRT 文件，支持 UTF-8、UTF-16 和 GB18030 编码。
- 按字幕块查看原文、时间码、问题类型、问题说明和修改建议。
- 支持英文大小写、拼写、空格、断句、缩写断行、行数与专名检查。
- 支持人工复核、填写审查结论和保留原始字幕。
- 可导出修正版 SRT、项目配置及校对报告。
- 提供 SRT 转 SCC、原始字幕打包等辅助功能。

### 同步画面复核

- 画面检测与 SRT 校对共用同一个本地视频实例，切换页面不重复导入。
- 支持横屏或竖屏预览比例。
- 根据字幕时间码定位对应画面。
- 显示字幕文本框，并提示可能超出画框的内容。
- 支持逐帧前后检查，帧号、时间码和帧率同步显示。

### 本地历史与导出

- 画面检测和 SRT 校对历史分类保存。
- 检测报告采用画面检测与 SRT 校对左右分栏展示。
- 历史报告保留异常事件缩略图，并设有本地存储容量上限。
- 支持 HTML / CSV / JSON 检测报告、项目配置和字幕结果导出。
- 所有检测和校对均在浏览器本地完成，数据不会主动上传。

## 运行环境

- **推荐浏览器**：最新版 Microsoft Edge 或 Google Chrome。
- **操作系统**：Windows、macOS 或 Linux，需能够运行上述现代浏览器。
- **运行要求**：启用 JavaScript，并允许浏览器读取用户主动选择的本地文件。
- **视频支持**：MP4 / MOV / MKV / WebM / TS；实际编码支持取决于浏览器 WebCodecs 和系统解码能力。
- **运行依赖**：无需 Node.js、npm、Python 包、数据库或后端服务。

> ProRes、MPEG-2 等浏览器不支持的编码会给出明确提示，建议先转码为 H.264 / H.265。Firefox、Safari 的支持情况取决于具体版本和系统编解码环境。

## 安装与运行

### 方法一：直接下载使用

1. 在仓库页面点击 **Code → Download ZIP**。
2. 解压下载的压缩包。
3. 使用 Edge 或 Chrome 打开根目录中的 `index.html`。
4. 页面加载完成后即可离线使用，无需执行安装命令。

### 方法二：通过 Git 克隆

```bash
git clone https://github.com/viper3jkl-wq/viper3.git
cd viper3
```

然后使用浏览器打开 `index.html`。

### 可选：通过本地 HTTP 服务运行

直接打开 HTML 已能满足基本使用。如果浏览器对 `file://` 页面的本地功能有限制，可在仓库目录运行：

```bash
python -m http.server 8080
```

再访问：

```text
http://localhost:8080
```

此处的 Python 仅用于提供可选的静态文件服务，不是应用运行依赖。

## 使用说明

### 1. 画面检测

1. 打开「画面检测」页面。
2. 点击「添加视频」或「导入文件夹」，选择待检测素材。
3. 选择检测预设；需要时再调整检测阈值和分析帧率。
4. 点击「开始检测」，等待任务完成。
5. 在结果表格中查看异常位置，通过统一播放器逐帧复核。
6. 点击异常时间码或缩略图，可直接定位到对应帧。
7. 根据需要导出检测报告，或在「检测报告」页面回看历史任务。

### 2. SRT 字幕校对

1. 切换到「SRT 字幕校对」页面。
2. 拖入或选择一个或多个 SRT 文件。
3. 如需画面对照，导入对应视频并选择横屏或竖屏比例。
4. 点击「开始校对」，查看系统列出的错误和警告。
5. 逐条复核问题，填写人工结论或修改建议。
6. 导出修正版 SRT、校对报告或项目配置。

### 3. 历史报告

- 画面检测与字幕校对记录分别归档。
- 检测报告按类型分栏展示，减少长距离滚动。
- 浏览器清理站点数据后，本地历史可能无法恢复，请及时导出需要长期保留的报告。

## 注意事项

- 画面异常检测用于初检和定位，疑似问题仍需结合原始素材人工复核。
- 自动识别帧率失败时会回退并在界面标注「估算」，批量检测前应确认帧率。
- 大型视频或大批量任务会消耗较多内存和处理时间，建议分批执行。
- 浏览器无法解码的容器或编码不能完成逐帧检测，建议先转码为 H.264 / MP4。
- 本地路径导入能力受浏览器安全策略影响；优先使用文件选择器或文件夹导入。

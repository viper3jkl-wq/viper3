# Viper3 · 本地视频质检与 SRT 字幕校对工具

Viper3 是一款在浏览器中本地运行的视频质检与字幕校对工具，集画面异常检测、SRT 批量校对、同步视频复核和历史报告管理于一体。应用以单个 HTML 文件交付，无需安装依赖、无需后端服务，素材不会主动上传到云端。

## 主要功能

### 画面异常检测
- 导入单个视频、多个视频或整个文件夹。
- 检测黑帧与疑似夹帧，并提供严格、均衡、宽松三种预设。
- 可调整像素亮度、暗像素占比、持续时长、画面突变和回归阈值等参数。
- 显示检测进度、异常时间点、置信度和结果汇总。
- 支持视频实时预览、检测结果定位和历史报告回看。

### SRT 字幕校对
- 批量导入 SRT 文件，支持 UTF-8、UTF-16 和 GB18030 编码。
- 按字幕块查看原文、时间码、问题类型、问题说明和修改建议。
- 支持人工复核、填写审查结论和保留原始字幕。
- 可导出修正版 SRT、项目配置及校对报告。
- 提供 SRT 转 SCC、原始字幕打包等辅助功能。

### 同步画面复核
- 导入本地视频并选择横屏或竖屏预览比例。
- 根据字幕时间码定位对应画面。
- 显示字幕文本框，并提示可能超出画框的内容。

### 本地历史与导出
- 画面检测和 SRT 校对历史分类保存。
- 支持报告、项目配置和字幕结果导出。
- 数据仅保存在当前浏览器和本机，清理浏览器站点数据会删除本地历史记录。

## 运行环境

- **推荐浏览器**：最新版 Microsoft Edge 或 Google Chrome。
- **操作系统**：Windows、macOS 或 Linux，需能够运行上述现代浏览器。
- **运行要求**：启用 JavaScript，并允许浏览器读取用户主动选择的本地文件。
- **视频支持**：取决于浏览器支持的容器和编码，推荐使用通用的 H.264 / MP4 文件。
- **运行依赖**：无需 Node.js、npm、Python 包、数据库或后端服务。

> Firefox、Safari 以及 MXF、MTS、M2TS 等格式的实际支持情况取决于具体浏览器和编解码环境，未作为本版本的主要验证环境。

## 安装步骤

### 方法一：直接下载使用

1. 在仓库页面点击 **Code → Download ZIP**。
2. 解压下载的压缩包。
3. 使用 Edge 或 Chrome 打开根目录中的 `index.html`。
4. 页面加载完成后即可离线使用，无需执行安装命令。

### 方法二：通过 Git 克隆

```bash
git clone https://github.com/viper3jkl-wq/viper3.git
cd viper3
```

然后使用浏览器打开 `index.html`。

### 可选：通过本地 HTTP 服务运行

直接打开 HTML 已能满足基本使用。如果浏览器对 `file://` 页面的本地功能有限制，可在仓库目录运行：

```bash
python -m http.server 8080
```

再访问：

```text
http://localhost:8080
```

此处的 Python 仅用于提供可选的静态文件服务，不是应用运行依赖。

## 使用说明

### 1. 画面检测

1. 打开「画面检测」页面。
2. 点击「添加视频」或「导入文件夹」，选择待检测素材。
3. 选择检测预设；需要时再调整检测阈值和分析帧率。
4. 点击「开始检测」，等待任务完成。
5. 在结果表格中查看异常位置，并通过预览画面进行人工复核。
6. 根据需要导出检测报告，或在「检测报告」页面回看历史任务。

### 2. SRT 字幕校对

1. 切换到「SRT 字幕校对」页面。
2. 拖入或选择一个或多个 SRT 文件。
3. 如需画面对照，导入对应视频并选择横屏或竖屏比例。
4. 点击「开始校对」，查看系统列出的错误和警告。
5. 逐条复核问题，填写人工结论或修改建议。
6. 导出修正版 SRT、校对报告或项目配置。

### 3. 历史报告

- 画面检测与字幕校对记录分别归档，避免不同类型结果混排。
- 浏览器清理站点数据后，本地历史可能无法恢复，请及时导出需要长期保留的报告。

## 注意事项

- 画面异常检测用于初检和定位，疑似问题仍需结合原始素材人工复核。
- 分析帧率应与原片一致，否则可能影响时间码和异常持续时长判断。
- 大型视频或大批量任务会消耗较多内存和处理时间，建议分批执行。
- 浏览器无法解码的视频不能完成逐帧检测，建议先转码为 H.264 / MP4。
- 本地路径导入能力受浏览器安全策略影响；优先使用文件选择器或文件夹导入。
